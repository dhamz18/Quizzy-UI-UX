# Quizzy – Gamified College Learning App

## About the Project
Quizzy is a gamified mobile learning app concept designed to make semester-based learning fun and interactive for college students.

## Key Features
- Student-friendly welcome screen
- Interactive home dashboard
- Semester and subject discovery
- Multiple-choice quiz interface
- Score and leaderboard concept
